# sgi-bcrp
Sistema de gestión de incidentes regulatorios BCRP
## Descripción
Plataforma para registrar, clasificar y dar seguimiento a incidentes de disponibilidad de servicios de las entidades financieras del sistema de pagos digitales peruano (Etapa 1).

## Tecnologías
Java 17, Spring Boot 3, PostgreSQL 15, RabbitMQ y Angular.
